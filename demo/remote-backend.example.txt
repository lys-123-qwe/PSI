# Optional remote real backends.
#
# The Python demo can run in two ways:
#   1. demo mode only: leave this file out (or keep it empty/comments only);
#   2. real data mode: point to one or more Linux servers that run this same
#      demo and have MYPSI_BIN configured, then copy this file to
#      remote-backend.txt.
#
# Copy:
#   cp remote-backend.example.txt remote-backend.txt
#
# Put one URL per line, priority order.  The first reachable backend with a
# real binary wins; if it cannot accept the run, the next one is tried.
#
#   http://192.0.2.10:8787
#   http://192.0.2.11:8787
#
# Same Linux host, two isolated instances:
#   http://192.0.2.10:8787    (MYPSI_PORT_BASE=1200 -> 1212/1213)
#   http://192.0.2.10:8788    (MYPSI_PORT_BASE=1320 -> 1332/1333)
#
# On each machine you can put your own backend first and the colleague's
# second, so both sides keep working when either instance is down.
#
# Windows shortcut:
#   connect-server.cmd -Primary http://192.0.2.10:8787 -Backup http://192.0.2.11:8787
#
# Full two-backend deployment guide: BACKENDS.md
#
# Do not commit remote-backend.txt.  It is in .gitignore.
