PSI Demo 真实数据样例说明
==========================

所有数据均为合成数据，不包含真实用户、订单或患者信息。
统一规模：A 方 1,200 行，B 方 1,000 行，C 方 800 行；三方共同元素 300 条。
一键演示：k=200 会达到门限并输出 300 条交集；k=400 会输出 ⊥。

1. 广告转化归因（ad_*.txt）
   A 广告平台：曝光名单
   B 商家：成交订单
   C 支付机构：支付流水
   元素格式：uid_ + 6 位十六进制，例如 uid_00012c
   含义：同一条 uid 在三方都出现，表示该脱敏用户既被曝光、又成交、又完成支付。
   文件：ad_A.txt / ad_B.txt / ad_C.txt

2. 拼车路线匹配（ride_*.txt）
   A 司机：轨迹网格
   B 乘客：路线网格
   C 调度：路网索引
   元素格式：geo_<纬度>_<经度>，例如 geo_31.230_121.470
   含义：一行代表约 100 米地理网格；三方共同网格表示司机和乘客都经过、且调度路网覆盖的路段。
   文件：ride_A.txt / ride_B.txt / ride_C.txt

3. 基因医疗比对（gene_*.txt）
   A 患者：脱敏位点
   B 医院：参考库
   C 科研库：标注位点
   元素格式：locus_rs + 6 位数字，例如 locus_rs100001
   含义：一行代表一个脱敏位点 ID；三方共同位点用于演示科研/辅助诊断的门限判断，不对应真实基因数据。
   文件：gene_A.txt / gene_B.txt / gene_C.txt

注意：页面会把每行原文在浏览器本地做 SHA-256，只上传 128-bit 哈希；
生产环境不能直接对手机号等低熵数据使用裸 SHA-256，应换用 OPRF 或加盐方案。
